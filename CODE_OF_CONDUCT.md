# Code of Conduct

## Our pledge
We want participation in CryptaKey to be a harassment-free, welcoming experience for everyone, regardless of age, background, identity, experience level or nationality.

## Expected behaviour
- Be respectful and constructive; critique code and ideas, not people.
- Assume good intent and ask clarifying questions.
- Keep discussions on topic and help newcomers learn.
- Handle security topics responsibly (see [SECURITY.md](SECURITY.md)).

## Unacceptable behaviour
- Harassment, insults, discrimination or personal attacks.
- Publishing others' private information.
- Posting real credentials or secrets in issues or pull requests.

## Enforcement
Maintainers may edit or remove comments, commits and issues that violate this code and may restrict participation. Report concerns by contacting the maintainer through the GitHub profile: <https://github.com/hamidrafique2-boop>.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
